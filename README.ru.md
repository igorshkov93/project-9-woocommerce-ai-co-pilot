# WooCommerce AI Co-pilot

AI-ассистент для владельцев магазинов на WooCommerce, работающий через
Telegram. Отвечает на аналитические вопросы о магазине, готовит черновики
маркетинговых текстов и выполняет административные действия на естественном
языке — на основе LLM tool-calling, оркестрация в n8n.

> Статус: основные сценарии реализованы и работают сквозным образом; идёт
> финальная проверка двух недавних исправлений.

## Зачем это нужно

Управление небольшим магазином на WooCommerce означает постоянное
переключение между wp-admin, таблицами и маркетинговыми инструментами просто
чтобы ответить на рутинный вопрос или выполнить рутинное действие. Этот
ассистент заменяет это переключение разговором в Telegram:

- **"Как прошла эта неделя?"** — вместо того чтобы вручную собирать отчёт,
  владелец спрашивает простым языком и сразу получает сводку, либо получает
  её автоматически каждый день в виде дайджеста в Slack.
- **Письмо для возврата покупателя с брошенной корзиной** — вместо написания
  текста с нуля, ассистент готовит черновик в стиле магазина, по запросу.
- **Целевой купон для плохо продающейся категории** — вместо того чтобы
  разбираться в интерфейсе купонов WooCommerce и вручную определять
  категорию, владелец просто описывает, что нужно, и подтверждает
  предложение перед тем, как что-либо будет создано. Ни одно действие не
  записывается в магазин без явного подтверждения человеком.

Цель: превратить повседневное администрирование магазина в сообщение в
Telegram, занимающее пять секунд, не давая LLM неконтролируемый доступ на
запись в магазин.

## Возможности

- Ежедневные сводки по заказам и выручке
- Анализ товаров с наибольшим количеством возвратов
- Черновики писем для брошенных корзин
- Создание купонов с подтверждением человеком
- Плановый ежедневный дайджест в Slack

## Технологический стек

| Слой | Технология |
|---|---|
| Интерфейс | Telegram Bot API |
| Оркестрация | n8n (self-hosted, Docker) |
| Reasoning | Gemini Flash (маршрутизация, tool calling), Claude Haiku (генерация текста) |
| Векторное хранилище | Qdrant |
| Источник данных | WooCommerce REST API |
| Уведомления | Slack (прямой вызов API — см. [ADR 0009](docs/adr/0009-orders-digest-to-slack.md)) |

## Архитектура

Единый Telegram-шлюз маршрутизирует каждое входящее сообщение или нажатие
кнопки в воркфлоу AI Agent, который работает с шестью инструментами (запросы
к магазину, аналитика, предложение купона, черновики писем, дайджест в
Slack), каждый со своим саб-воркфлоу. Действия, изменяющие состояние
магазина (создание купона), проходят через явный поток propose → confirm:
агент может только *предложить*, и ничего не создаётся, пока владелец не
нажмёт кнопку подтверждения, которая запускает отдельный, узко
сфокусированный воркфлоу.

Архитектурные решения и их компромиссы задокументированы как ADR в
[docs/adr/](docs/adr/):

- [0008 — Оркестрация AI-агента](docs/adr/0008-ai-agent-orchestration.md)
- [0009 — Дайджест заказов в Slack](docs/adr/0009-orders-digest-to-slack.md)
